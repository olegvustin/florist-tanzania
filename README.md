# Флорист. Танзания — Цветы Африки

Версия игры v0.15.125. Оптимизированный комплект для **однократной загрузки через браузер GitHub** (меньше 100 файлов). Часть небольших изображений встроена в `index.html` без изменения их качества. Остальные лежат в `assets/game/`.

1. Создайте **публичный** репозиторий `florist-tanzania`.
2. На странице репозитория выберите **Add file → Upload files** и **перетащите СОДЕРЖИМОЕ папки `ЗАГРУЗИТЬ_НА_GITHUB`**, а не саму папку. Сохраняйте подпапку `assets/game/`. GitHub допускает до 100 файлов за одну загрузку.
3. Нажмите **Commit changes**.
4. Выберите **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
5. Ссылка на игру: `https://ВАШ-ЛОГИН.github.io/florist-tanzania/`.
6. Для Tilda используйте T123 код из предыдущего комплекта, заменив `GITHUB_USERNAME` своим логином.

Важно: при добавлении через веб-интерфейс каждый файл должен быть меньше 25 MiB, размер index.html ~7-8MB. Репозиторий должен содержать `index.html` **в корне**, а не во вложенной папке.
