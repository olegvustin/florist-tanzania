# Плантация редких цветов — модуль v1

Добавлен самостоятельный модуль `features/rare-plantation.js`. **Он пока не подключён к `index.html` и не изменяет опубликованную игру.** Это осознанно: текущий `index.html` содержит ~23 МБ и требуется безопасное редактирование исходного файла.

## Правила
- Три редких цветка отсутствуют в обычном рыночном каталоге: Королевская протея, Золотая стрелиция, Огненная глориоза.
- Три грядки; выращивание занимает 10, 15 и 20 минут соответственно (предварительный баланс, можно менять).
- Собранные цветы попадают в отдельный запас; метод `consume` позволяет потратить их при сборке букета.
- Настоящая интеграция с экономикой и инвентарём происходит только через `onHarvest`. Не добавляйте цветок и в основной инвентарь, и в отдельный запас без единой схемы учёта.
